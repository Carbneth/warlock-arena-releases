This repository distributes installers and automatic-update packages only. Game source is not published here.

Download the Windows Setup executable from [the latest release](https://github.com/Carbneth/warlock-arena-releases/releases/latest). Install per user; no Godot editor or .NET SDK is required.

The launcher checks this public repository for updates before starting the game. Updates are downloaded and verified by Velopack, then applied while the game is closed. If the update service is unavailable, the launcher offers to play the existing installation.

QHD (2560Ã—1440) is supported. In Settings choose native-desktop fullscreen for a QHD monitor, or a window size fitting your desktop. Display changes require confirmation and automatically revert after 15 seconds.

These prototype builds are unsigned; Windows SmartScreen may warn. No kernel anti-cheat, accounts, matchmaking or permanent progression is included. Local CheatEngine/ArtMoney name checks are bypassable and are not strong anti-cheat. Direct-IP multiplayer requires matching game revisions and reachable UDP hosting.
